# Pattachitra Studio— Traditional Art of Odisha

A portfolio website for a Pattachitra artist, showcasing traditional Odisha art. Built with **Next.js** for the website and **Sanity CMS** for content management, including a contact enquiry system.

---

## Overview

This repository is organized into two independent projects, each with its own dependencies:

| Folder    | Purpose                                              |
| --------- | ----------------------------------------------------- |
| `web/`    | The public-facing Next.js website                     |
| `studio/` | The Sanity Studio used to manage content              |

Since each folder has its own `package.json`, they are installed and run **separately**.

---

## Tech Stack

| Layer         | Tool                     |
| ------------- | ------------------------ |
| Framework     | Next.js 16 (App Router)  |
| CMS / Studio  | Sanity                   |
| Styling       | Tailwind CSS             |
| Language      | TypeScript               |

## Getting Started

### 1. Clone the Repository

```bash
git clone https://github.com/PriyaM1410/Pattachitra.git
cd Pattachitra
```

### 2. Install Dependencies

Each folder must be installed individually.

**Web:**

```bash
cd web
npm install
```

**Studio:**

```bash
cd studio
npm install
```

### 3. Configure Environment Variables

Create a `.env.local` file inside the `web/` folder (this file is git-ignored — never commit it):

```
NEXT_PUBLIC_SANITY_PROJECT_ID=your_project_id
NEXT_PUBLIC_SANITY_DATASET=production
SANITY_API_TOKEN=your_write_token
```

| Variable                          | Where to find it                                                  |
| ---------------------------------- | ------------------------------------------------------------------ |
| `NEXT_PUBLIC_SANITY_PROJECT_ID`    | [manage.sanity.io](https://manage.sanity.io) → project → Settings  |
| `NEXT_PUBLIC_SANITY_DATASET`       | Same as above (usually `production`)                               |
| `SANITY_API_TOKEN`                 | Sanity → API → Tokens (requires **Write** access, used by the contact form) |

## Running the Project

### Web App

```bash
cd web
npm run dev
```

Runs at [http://localhost:3000](http://localhost:3000). The page auto-reloads as files are edited. Stop the server with `Ctrl + C`.

**Other commands (inside `web/`):**

```bash
npm run build   # production build (also checks for errors)
npm run start   # run the production build locally
```

### Sanity Studio

```bash
cd studio
npm run dev
```

Runs at [http://localhost:3333](http://localhost:3333). Log in with a Sanity account the first time (`npx sanity login`).

**Deploying Studio changes** — only required when the Studio's structure changes (new field, new content type, layout change):

```bash
cd studio
npx sanity deploy
```

This republishes the hosted Studio and does **not** affect the web app.

---

## Editing Content (No Code Required)

Once inside the running Studio, artworks, categories, and testimonials can be added or edited directly, and contact enquiries can be viewed. Changes are saved immediately — no rebuild of the web app is needed.

## Reinstalling Dependencies

If a pulled change touches a `package.json`, reinstall dependencies in that specific folder:

```bash
cd web      # or: cd studio
rm -rf node_modules package-lock.json
npm install
```

**PowerShell (Windows):**

```powershell
Remove-Item -Recurse -Force node_modules
Remove-Item package-lock.json
npm install
```

**Files you don't need to touch:**

- `.next/` and `node_modules/` — auto-generated, safe to delete anytime (they'll come back with `npm run dev` / `npm install`)
- `next-env.d.ts` — auto-generated by Next.js, don't edit manually
